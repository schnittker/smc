# Recherche: Fibonacci-Pullback und Chandelier-Trailing-Trend

Stand: 24.10.2026

## 1. Idee

- **Nr. 52 Fibonacci-Pullback:** Nach einem Impuls (Swing-Tief → Swing-Hoch) wird im Bereich 50–61,8 % Rücklauf in Trendrichtung eingestiegen. Der Stop liegt unter dem Impulsursprung, das Ziel ist das Impulshoch.
- **Nr. 53 Chandelier Exit (Le Beau):** Trendfolge mit einem Trailing-Stop von 3 ATR unter dem höchsten Hoch seit Einstieg. Gewinne laufen lassen, Verluste begrenzen. Der Einstieg erfolgt per 55-Tage-Ausbruch (Turtle).
